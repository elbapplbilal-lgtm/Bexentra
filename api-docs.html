مهم للمطورين

الخدمة متاحة للقراءة العامة، ولكن CORS في المتصفحات يسمح حالياً بموقع BEXENTRA على GitHub Pages فقط. استخدام API من مواقع أخرى داخل المتصفح يحتاج إعداد CORS مستقل. لا يوجد ضمان لتوفر الخدمة أو سرعة الطلبات.

GET/liveأحدث بيانات الشبكة

 
يعرض عيّنة من معاملات أحدث بلوك متاح، أو سجلات محفوظة عند تعذّر الاتصال. ليس كل معاملات الشبكة.

 
المعاملات المطلوبة
chain: bnb أو solana · limit: من 1 إلى 50 (الافتراضي 8)

 
مثال طلب (استبدل أي معرّف نموذجي بقيمة حقيقية)
  
 

 
https://br-old-sun-b5txcoym-bexentraapi.compute.c-7.us-east-2.aws.neon.tech/live?chain=bnb&limit=8

 




 
GET/blocksأحدث البلوكات المحفوظة

 
قائمة البلوكات التي خزّنها فهرس BEXENTRA، وليست كل البلوكات التاريخية.

 
المعاملات المطلوبة
chain · limit: من 1 إلى 50

 
مثال طلب (استبدل أي معرّف نموذجي بقيمة حقيقية)
  
 

 
https://br-old-sun-b5txcoym-bexentraapi.compute.c-7.us-east-2.aws.neon.tech/blocks?chain=bnb&limit=10

المعاملات المطلوبة

GET/txتفاصيل معاملة

 
ابحث عن معاملة بالهاش. حالة التنفيذ والرسوم لا تُعرض باعتبارها مؤكدة إلا بعد التحقق من الشبكة.

المعاملات المطلوبة
chain · address: عنوان صحيح للشبكة

 
مثال طلب (استبدل أي معرّف نموذجي بقيمة حقيقية)
  
 

 
https://br-old-sun-b5txcoym-bexentraapi.compute.c-7.us-east-2.aws.neon.tech/balance?chain=bnb&address=0x0000000000000000000000000000000000000000

chain=bnb · address · limit: من 1 إلى 50

https://br-old-sun-b5txcoym-bexentraapi.compute.c-7.us-east-2.aws.neon.tech/token-transfers?chain=bnb&address=0x0000000000000000000000000000000000000000&limit=20

الأخطاء والحدود


200
نجح الطلب، لكن تحقق من source وcoverage لمعرفة مصدر البيانات ومدى اكتمالها.


400
مُعامل غير صحيح، مثل عنوان محفظة غير صالح أو limit خارج المدى.


404
لم تُعثر على المعاملة أو البلوك ضمن النتائج التي أمكن التحقق منها.


503
المصدر أو قاعدة البيانات غير متاحة حالياً؛ لا تفترض أن الرصيد صفر.


دقة البيانات
مسارات /blocks و/transactions و/address و/token-transfers تعتمد على فهرس جزئي؛ /balance قراءة RPC للحظة الطلب؛ /price سعر سوق خارجي قد يتأخر. القيم native_balance وfee_native تُعرض بوحدات الشبكة الأولية (wei أو lamports). حالة null لا تعني نجاحاً أو فشلاً.
